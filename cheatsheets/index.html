Java

9 volumes

The language and the runtime. Interviewees who get Java right talk about what the compiler and the JVM are allowed to do, not just what the syntax says.

01 Java Basics Primitives vs wrappers, integer overflow, string immutability, pass-by-value, overload vs override.
02 Object-Oriented Programming Composition over inheritance, abstract classes vs interfaces, equals/hashCode contracts, SOLID.
03 Core Java Object contract, autoboxing and the Integer cache, checked vs unchecked exceptions, type erasure.
04 Collections Framework HashMap internals and resize, ArrayList vs LinkedList, fail-fast iterators, when each collection is wrong.
05 Java 8+ Functional interfaces, stream laziness and ordering, Optional's real purpose, method references.
06 Multithreading & Concurrency Executors and bounded queues, volatile vs synchronized, atomics and CAS, deadlock vs starvation.
07 JVM Internals & Memory Class loading, heap generations, GC selection and tuning, reading a heap dump under pressure.
08 Advanced Java Reflection and its costs, annotation processing, serialization hazards, records and sealed types.
09 Modern Java & Production Java 17/21 features, virtual threads, structured concurrency, diagnosing real incidents.

Spring

11 volumes

Framework behaviour, not API recall. Most Spring interviews are really asking where the container, the proxy, or the transaction boundary is going to surprise you.

01 Spring Core & the IoC Container BeanDefinition registration, the three DI styles, ApplicationContext events, lazy init.
02 Bean Lifecycle, Scopes & Advanced DI Full callback sequence, singleton vs prototype, circular references, FactoryBean.
03 AOP & Proxying JDK vs CGLIB selection, the self-invocation trap, and every proxy-related silent failure.
04 Transaction Management Propagation levels, rollback-on rules, checked vs runtime exceptions, self-invocation.
05 Spring MVC & the Web Layer The DispatcherServlet request path, filters vs interceptors, async and error handling.
06 Spring Data JPA & Persistence N+1 queries, the persistence context, lazy loading outside a session, and ddl-auto's damage.
07 Spring Boot & Auto-Configuration @Conditional ordering, starters, externalized configuration and profile precedence.
08 Spring Security The filter chain, authentication vs authorization, method security, OAuth2 and JWT failure modes.
09 Testing & Production Troubleshooting Slice tests vs full context, mock boundaries, and diagnosing a running application.
10 WebFlux & Project Reactor Backpressure, cold vs hot streams, Schedulers, and the event-loop blocking mistake.
11 Spring Cloud & Distributed Systems Circuit breakers, retries, config and discovery, gateways, and idempotency at the edge.

Microservices

3 volumes

Distributed systems as a discipline rather than a Spring feature set. Every answer here is expected to carry a migration cost and a failure mode, not just a pattern name.

01 Foundations, Boundaries & Decomposition When not to split, DDD and bounded contexts, the modular monolith, Conway's law.
02 Communication, Data & Consistency Sync vs async, idempotency keys, the outbox pattern, sagas, CAP as an architecture question.
03 Operations, Platforms & Evolution Observability and SLIs, resilience budgets, progressive delivery, Kubernetes and service mesh.

Database

11 volumes

Framed around where the abstraction stops paying for itself: why SELECT * is a page-count problem before a bandwidth one, and what a shard key costs to undo.

01 Fundamentals & the Relational Model Pages and the buffer pool, tuples and attributes, ACID and what each clause actually guarantees.
02 SQL — DDL, DML & Constraints Types and their costs, primary/foreign keys, CHECK and UNIQUE, and constraint-driven write errors.
03 SQL — Queries, Joins, CTEs & Window Functions Join semantics and NULL, the LEFT JOIN that becomes an inner one, COUNT and fan-out.
04 Indexes, Query Planning & Execution B+ trees, page splits, leftmost prefix, composite index column order, reading EXPLAIN.
05 Transactions, Isolation & Concurrency Every isolation anomaly by name, lost updates, write skew, and SERIALIZABLE's catch.
06 Schema Design, Partitioning & Scaling Normalisation trade-offs, vertical vs horizontal split, shard key choice, when it becomes irreversible.
07 PostgreSQL MVCC snapshots, HOT updates, bloat, vacuum starvation, and the planner's costing choices.
08 MySQL & the InnoDB Engine Clustered indexes, gap and next-key locks, read views, and REPEATABLE READ's surprises.
09 Redis & Caching Strategies Eviction policies, TTL and expiry races, cache-aside, and stampede/penetration/avalanche.
10 NoSQL & Distributed Stores Cassandra tombstones, DynamoDB hot partitions, MongoDB documents vs relations, consistency knobs.
11 S3, Elasticsearch & Interview Bank Object storage consistency and presigned URLs, inverted indexes, and the consolidated bank.
